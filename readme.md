# 條碼掃描 ＆ 複製 (Barcode Scanner & Generator)

一個輕量級、免安裝的網頁版條碼與 QR Code 掃描器與生成工具。直接透過瀏覽器即可即時使用相機、上傳圖片或貼上剪貼簿內容來辨識條碼，並能將結果重新轉譯為高畫質的 SVG 或 PNG 檔案下載。

## 線上預覽 (Live Demo)

[https://ren1244.github.io/code-snap/](https://ren1244.github.io/code-snap/)

## 功能特色

* **三種輸入模式**：
    * **相機即時掃描**：支援手機或電腦鏡頭，具備即時裁切框與辨識。
    * **圖片檔案上傳**：支援常見的圖片格式進行解碼。
    * **剪貼簿貼上**：直接從截圖或複製的圖片中快速讀取條碼。
* **完美複製**：辨識成功後，系統會透過與原圖相同的編碼與參數重新繪製，高度還原原始條碼。
* **支援多種格式**：多種一維、二維條碼均可讀取並顯示內容。其中 **Code 39**、**Code 128** 以及 **QR Code** 可下載複製的條碼。
* **向量與點陣圖匯出**：可下載 **SVG 向量圖**（列印不失真）或 **PNG 圖片**。
* **純前端架構**：不需安裝額外 App、不上傳資料到雲端，保護隱私。

## 使用方式

1. 點擊[上方連結](https://ren1244.github.io/code-snap/)直接在瀏覽器中使用。
2. 點擊頁面上的按鈕選擇對應的掃描方式：
    * **開啟相機**：將條碼對準畫面中的綠色取樣框。
    * **開啟圖片**：選取本機儲存的條碼圖片。
    * **從剪貼簿**：複製圖片後直接點擊貼上（此功能適合電腦上操作，手機視瀏覽器支援而定）。
3. 辨識成功後，下方會顯示對應的格式與內文，並提供下載選項。
